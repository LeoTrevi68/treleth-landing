# Eliminación de datos de Chronos

CRF1Bot · Cubuti, parte de Treleth

Para solicitar la eliminación de tu información, escribe a **j.leopoldo.trevino.martinez@gmail.com** con el asunto **Eliminar información de Chronos**.

1. Describe la información que deseas eliminar.
2. Durante una sesión o prueba técnica, indica el número de WhatsApp con el que participaste.
3. Cuando se habilite la consulta por código y se elimine el vínculo telefónico, proporciona el código personal válido.

El responsable, José Leopoldo Treviño Martínez, solicitará únicamente los elementos necesarios para comprobar tu derecho a gestionar el registro y responderá dentro de los plazos legales aplicables, confirmando el resultado o los motivos de cualquier limitación. No envíes contraseñas ni códigos de acceso a WhatsApp.

El borrado automático está pendiente de implementación. Mientras tanto, puedes solicitar la eliminación por este canal. La eliminación en Chronos no elimina las copias en tu teléfono ni los registros que Meta o Cloudflare conserven conforme a sus propias políticas.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo, `treleth-landing`).
2. Sube `index.html`, `styles.css` y `README.md` a la raíz del repositorio.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`.
5. Guarda. GitHub mostrará la URL pública de la página en unos minutos.

El enlace de YouTube ya apunta al video indicado; GitHub, WhatsApp y correo también están configurados.
